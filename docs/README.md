# CodeChemBook Documentation Guide

This directory contains the Markdown source files that generate the documentation for the `codechembook` Python package.

We use **MkDocs** with the **Material for MkDocs** theme to build the site, and **mkdocstrings** to automatically extract API documentation from the Python docstrings.

## How Documentation is Deployed

The live documentation is hosted on GitHub Pages. You **do not** need to manually deploy the documentation. 

Deployment is fully automated via GitHub Actions (`.github/workflows/mkdocs.yml`). 

### When Does it Update?

The live website will automatically rebuild and update whenever a commit is pushed to the `main` or `1.4.0` branches. 

This includes:
1. **Direct Pushes**: Committing and pushing directly to `main` or `1.4.0`.
2. **Pull Request Merges**: When you create a feature branch, make changes, open a Pull Request, and then **merge** that Pull Request into `main` or `1.4.0`. The merge commit triggers the action.

*Changes made on feature branches will not update the live site until they are merged.*

## How to Preview Changes Locally

If you are modifying these `.md` files or updating Python docstrings and want to see how they look before merging to `main`:

1. Ensure you have the documentation dependencies installed:
   ```bash
   pip install mkdocs-material mkdocstrings[python] mkdocs-gen-files
   ```
2. Run the live-reload server from the project root:
   ```bash
   python3 -m mkdocs serve
   ```
3. Open your browser to `http://127.0.0.1:8000`. The page will automatically refresh every time you save a `.md` or `.py` file.

## Modifying the Symbols Table

The tables in the `Symbols` section are automatically generated by the script `docs/gen_symbols.py`. It reads the files in `src/codechembook/symbols/` and parses both the symbols and the inline `#` comments. 

To add or update a symbol description in the documentation, simply update the inline comment next to the variable definition in the corresponding Python file.
